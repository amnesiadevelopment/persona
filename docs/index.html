persona
Two engines

One manager, two ways to disappear

Pick the browser engine per profile. Each persona's fingerprint is seeded deterministically from its name — identical across restarts, unrelated between personas.

CHROMIUM

fingerprint-chromium

An ungoogled build with canvas, WebGL, audio, fonts, hardware and platform spoofed deterministically. Extensions add locale and per-profile entropy. Available on every OS.

FIREFOX

patched Firefox 150+

Spoofing done at the C++ level — no CDP or webdriver tells. The most invisible profile when that's what matters.

Features

Everything to keep accounts apart

Separate, human-like identities — fingerprint, network, storage and login, all handled per persona.

Per-persona fingerprint

Canvas, WebGL, audio, fonts, hardware and platform spoofed deterministically — stable across restarts, unlinkable between personas.

Geo follows the proxy

Locale, timezone and geolocation track the proxy's country so they match the exit IP. DNS and WebRTC stay inside the tunnel.

Named proxy store

Reusable SOCKS5/HTTP proxies with a geo/IP check and one-click rotation, assigned to profiles by name.

mTLS certificates

Add a client certificate and assign it to a profile. Presented only to its admin site — never elsewhere — and it stays inside persona, never in the OS store.

Mobile personas

Android and iOS profiles from real device presets: user-agent, screen, touch and Client-Hints.

Resolution & HiDPI

Report any screen resolution while the real window stays native and readable — no window-size tell.

Cookies, bookmarks, import/export

File-based cookie import/export, reusable bookmark pools, and full profile import/export.

Local automation API

An opt-in local server exposes profile management and a CDP port, so an MCP client like Claude can drive personas. Off by default.

Stable & self-updating

The UI runtime is bundled; each engine downloads itself on first use. persona updates itself in place — most updates take seconds.
