persona

A local, single-operator anti-detect browser manager. Run many accounts by hand, each with its own fingerprint — without linking them.

Two engines, one manager

Pick the browser engine per profile. Each persona's fingerprint is seeded deterministically from its name — identical across restarts, unrelated between personas.

Chromium

An ungoogled fingerprint-chromium build. Canvas, WebGL, audio, fonts, hardware and platform are spoofed deterministically; extensions add locale and per-profile entropy. Available on every OS.

Firefox

A patched Firefox 150+ that spoofs at the C++ level — no CDP or webdriver tells. The most invisible profile when that matters.

Features

Everything you need to keep accounts separate and human-like.

▸ Per-persona fingerprint

Canvas, WebGL, audio, fonts, hardware and platform spoofed deterministically — stable across restarts, unlinkable between personas.

▸ Geo follows the proxy

Locale, timezone and geolocation track the proxy's country so they match the exit IP. DNS and WebRTC stay inside the tunnel.

▸ Named proxy store

Reusable SOCKS5/HTTP proxies with a geo/IP check and one-click rotation, assigned to profiles by name.

▸ mTLS certificates

Add a client certificate and assign it to a profile. It's presented only to its admin site — never anywhere else — and stays inside persona, never in the OS store.

▸ Mobile personas

Android/iOS profiles from real device presets: user-agent, screen, touch and Client-Hints.

▸ Cookies, bookmarks, import/export

File-based cookie import/export, reusable bookmark pools, and full profile import/export.

▸ Local automation API

An opt-in local server exposes profile management and a CDP port, so an MCP client like Claude can drive personas. Off by default.

▸ Resolution & HiDPI

Report any screen resolution while the real window stays native and readable — no window-size tell.

Download

The UI runtime is bundled; each browser engine downloads itself on first use. persona updates itself in place — most updates take seconds.

Honest about limits: persona aims for a clean, consistent, human-like profile — not magic invisibility. Passing one fingerprint checker isn't the same as passing systems that score TLS + IP + headers + behaviour together. Proxy quality and human behaviour matter as much as the fingerprint.
