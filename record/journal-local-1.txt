# workspace, so that a run whose runner dies mid-step still says how far
# it got. READ IT AS FOLLOWS:
#
#   BEGIN <tree>/<label>            the phase started
#   ALIVE <tree>/<label> elapsed=…  the phase was still running then
#   MARK  <tree> …                  a milestone between phases
#   END   <tree>/<label> rc=<n>     the phase finished, with its exit code

# ALIVE line bounds how far it got. That is a different statement from
# 'the phase failed', and this file is what keeps the two apart.
