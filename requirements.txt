# KEEP THIS BOUND IN LOCKSTEP WITH pyproject.toml — see the long comment there
# for the measured mechanism. Short version: flet builds macOS as two separate
# pip resolutions (arm64 + x86_64) and merges them, cryptography >=49 ships an
# arm64-ONLY macOS wheel (universal2 was dropped in 49.0.0), so the two passes
# resolve DIFFERENT versions and the merge collides them on the version-agnostic
# `_rust.abi3.so` filename — yielding a bundle whose metadata says 50.0.0 and
# whose shared object says 48.0.1, which cryptography refuses to import.
# <49 keeps both arches on the last universal2 line. Not a security pin; a
# range, so 48.0.x patches still land.
#
# THE darwin MARKER IS LOAD-BEARING — do not collapse these two lines into one.
# The two-pass merge is macOS-ONLY; Windows and Linux resolve once and cannot
# hit it. Measured with pip: without the cap win/linux resolve 50.0.0, WITH an
# unconditional cap they resolve 48.0.1 — so an unscoped bound would downgrade
# a security library two major versions on the platforms that were never broken
# (Linux passed 11/11 imports on 50.0.0). Scoped, it costs them nothing.
